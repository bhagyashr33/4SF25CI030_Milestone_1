### Milestone 1
This project explores a dataset using Python to understand its structure, data types, missing values, and patterns through data analysis and visualization.

Files :
- Practice_Code.ipynb  : Python notebook containing the analysis.
- synthetic.csv  : Dataset used.

Tools :
- Python
- Pandas
- Matplotlib
- Seaborn

Topics Covered : 

- Loading and inspecting a dataset using Pandas.
- Understanding dataset dimensions, column names, and data types.
- Exploring numerical and categorical features.
- Analyzing geographical coordinates using latitude and longitude.
- Creating scatter plots and visualizing relationships using Seaborn and Matplotlib.
- Performing exploratory data analysis to identify patterns in the dataset.
